# Portfolio

My personal portfolio site, built with React and Vite.

Live: https://wendyamahle.github.io/portfolio/

## Run locally

```bash
npm install
npm run dev
```

## Editing content

- Personal details and skills: `src/data/profile.js`
- Projects: `src/data/projects.js`

Pushing to `main` deploys the site to GitHub Pages automatically.
